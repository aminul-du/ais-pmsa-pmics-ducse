# Security Policy

## Scope
This private repository contains academic research for the Professional Masters in Information and Cyber Security (PMICS) program at the University of Dhaka.

## Contact
- Primary Maintainer: Md. Aminul Islam (aminul@aminul-du.com)

## Credential & Data Governance
- No API keys, tokens, SSH keys, or production credentials may be committed.
- Datasets in `datasets/` must contain anonymized or synthetic Bengali, Banglish, and English test prompts only.
